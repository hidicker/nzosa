Coding reconciliation

Load what your accounting system or spreadsheet already recorded, and every coding this app proposes is lined up against it. Where the two agree, that coding can become a rule you keep; where they differ, you can see which one is wrong. This is how a year gets coded back through without doing it line by line. Matching is on amount and nearest date.

How to get the file out of Xero
  1. Go to Reporting → Account Transactions.
  2. Select all accounts.
  3. Under columns, select all columns.
  4. Set Grouping/Summarising to None. This matters: grouped output hides the account each posting went to, which is the whole point of the check.
  5. Click Update, then Export → Excel.

Load the resulting .xlsx or .csv here. A chart of accounts export helps too, so a code and a name are recognised as the same account.

Loading a spreadsheet instead

Your own spreadsheet is accepted, and needs three columns:

  • Date and Amount — required, and found by those headings.
  • A column saying what each line was coded to. Its heading can be What, Account, Code, Coding, Category or Class — whichever yours uses.

If none of those headings fits, the file is not refused: you are shown the headings it found and can point at the right three columns yourself. Nothing needs renaming first.

History

Every change, most recent first, and how to put it back. The name is recorded with each change but nothing verifies it — this is attribution between people who trust each other, not an audit trail. The log stays on this machine and is not carried by an exported ledger.

Invoices

Which money settled which invoice. An invoice number on the bank line is believed outright; a recorded allocation is next; amount and date only when they are exact. Anything less is proposed rather than matched, because closing the gap means writing money off.

Entities & accounts

An account belongs to exactly one entity. A bank account may serve several, because one current account often pays for all of them. The GST treatment set here is what the returns use for anything coded to that account, so an account with none is an account whose GST would only be assumed.

Opening balances

What each account stood at before this ledger begins. Without them a balance sheet shows only the movement since the first bank line, which is a wrong balance sheet rather than a short one. Take them from a trial balance at the previous year end: it carries the cents and every account, so the figures balance on their own.

Import bank balances

An import can be missing a transaction, or hold the same one twice, and no total will show it — the total is made of exactly the rows that are there. The bank's daily balance is the outside witness. Export it from internet banking for the same period as the transactions, or type a few statement balances in below: a start and an end for an account are enough to show whether anything between them is missing.

Where to get the files

    What happens to duplicates

    Nothing is ever deleted automatically. Rows identical to one already in the ledger are marked duplicate and left out, so re-importing an overlapping statement is safe. Rows that only look like duplicates — the same amount and payee with a different bank serial, or a day apart on a feed with no serial — are marked review and kept, for you to decide.
